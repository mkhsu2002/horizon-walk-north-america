# Design: Route 66 Walking
Maintained from the Kiro CLI draft.

Static preview modules separate the Demo engine, Manual date ledger and passport renderer. Use integer millimetres and stable award IDs. Required steps for a distance are rounded up only for labels; never use rounded display kilometres to gate an award. Each Demo batch ID is accepted at most once. A Manual day has one record in the fixed challenge timezone. Never read Demo progress in Manual UI. Keep keys distinct, preserve earned awards after corrections and only put a saved postcard in print output. Deploy `web/` only; specs, tests and research are not public application assets.
